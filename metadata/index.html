Походження і обробка

Методика

Вихідні растровані значення WorldPop розподілено між адміністративними полігонами пропорційно площі їх перетину:

Pj=∑iViA(Ci∩Hj)A(Ci)
  1. Атрибути меж Ukraine Legacy Admin 3 скоригував Олексій Бойко.
  2. Для кожної комірки растра обчислено частку площі перетину з кожним полігоном.
  3. Результати підсумовано та округлено до цілих осіб.
  4. Геометрію перетворено в WGS 84 / EPSG:4326.
  5. Після розрахунку населення геометрію спрощено з допуском 100 м для вебвідображення.

DQV · якість даних

Обмеження та належне використання

Відомі обмеження

Ці дані надаються 'як є', без жодних заяв щодо їхньої точності.

Значення чисельності є модельованими оцінками на основі продукту WorldPop із приблизною роздільністю 100 м. Набір успадковує невизначеність демографічних джерел, методів прогнозування та просторового моделювання WorldPop.

Доцільно використовувати

  • для пошукових досліджень і візуалізації;
  • для порівняння загальних просторових закономірностей;
  • для агрегованого аналізу на рівні громад або вище;
  • для визначення територій для подальшого дослідження.

Не використовувати як єдине джерело

  • для офіційних підсумків населення;
  • для оцінки переміщення населення в реальному часі;
  • для юридичних, виборчих або непідтверджених гуманітарних рішень;
  • для аналізу будівель, ділянок, домогосподарств або точних змін дуже малих територій.

Dublin Core · description

Identification

The dataset combines a fixed administrative boundaries (NUTS 3) with approximately 100-metre WorldPop modelled population rasters. Grid-cell values were allocated to polygons in proportion to intersection area and rounded to whole persons. Geometry was simplified by 100 metres after the population calculation for efficient web display.

Six state territories are retained for complete spatial coverage: the Chornobyl Exclusion Zone and five major water bodies. Values assigned to water-body polygons are raster-cell intersection artefacts and do not represent residents of those water bodies.

Provenance and processing

Method

Source WorldPop raster values were allocated to administrative polygons in proportion to intersection area:

Pj=∑iViA(Ci∩Hj)A(Ci)
  1. Oleksii Boiko adjusted the Ukraine Legacy Admin 3 boundary attributes.
  2. Each raster cell was allocated by its proportional area of intersection with each polygon.
  3. Results were summed and rounded to whole persons.
  4. Geometry was transformed to WGS 84 / EPSG:4326.
  5. After population calculation, geometry was simplified with a 100-metre tolerance for web display.

DQV · data quality

Limitations and appropriate use

Known limitations

This data is provided 'as is,' without any statements regarding its accuracy.

Population values are modelled estimates derived from WorldPop’s approximately 100-metre gridded population product and are not official census counts. Source uncertainty is inherited from WorldPop’s input demographic data, projection methods and spatial modelling.

Appropriate for

  • exploratory research and visualization;
  • comparison of broad spatial patterns;
  • aggregated analysis at hromada or larger levels;
  • identifying areas for further investigation.

Not as the sole source for

  • official population totals;
  • real-time displacement estimates;
  • legal, electoral or uncorroborated humanitarian decisions;
  • building-, parcel-, household-level or precise very-small-area change analysis.

Verified quality measurements

  • 1,780 spatial features; every feature has geometry.
  • 0 missing values across p2021–p2026.
  • 1 missing TYPE value and 4 spelling variants in TYPE, retained unchanged.
